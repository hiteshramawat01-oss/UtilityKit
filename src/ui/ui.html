What this can and can’t do

It can find the Google Drive link on this file’s “For Designers” page, copy it or open it, and add one when there is none. A link you add is written on that page as “GDrive link to folder”.

It shows one link: the one named “GDrive link to folder”, or the first Google Drive link on the page if there isn’t one with that name.

It can’t see inside Google Drive. It doesn’t check that a link works or who has access, and it never uploads, downloads or syncs files. The plugin never contacts Google.

Updates

Checks the UtilityKit repository on GitHub for a newer version and can install it here. It only runs when you press the button.
