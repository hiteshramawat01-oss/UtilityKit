What this can and can’t do

It can find Google Drive and Google Docs hyperlinks that are already in this file’s “For Designers” page, open or copy them, and add new link text to that page.

It can’t see inside Google Drive. It doesn’t check that a link works or who has access, and it never uploads, downloads or syncs files. The plugin never contacts Google.
