What this can and can’t do

It can find the Google Drive link on this file’s “For Designers” page, copy it or open it, and add one when there is none. A link you add is written on that page as “GDrive link to folder”.

It shows one link: the one named “GDrive link to folder”, or the first Google Drive link on the page if there isn’t one with that name.

It can’t see inside Google Drive. It doesn’t check that a link works or who has access, and it never uploads, downloads or syncs files. The plugin never contacts Google.

What it is

UtilityKit is a small Figma plugin for the everyday chores that slow design work down: naming frames, merging layers for print, and finding the project’s Google Drive link.

Why it was made

These jobs are simple, but doing them by hand takes time and comes out a little different for each person. UtilityKit does each one in a click, the same way every time.

  • Less typing. It reads the page name, frame size and client from the file instead of asking.
  • The same names for everyone. Frames follow the team naming guideline.
  • One job, one button. Nothing to set up and nothing to learn.
  • Safe to try. Nothing changes until you press a button, and ⌘Z / Ctrl+Z undoes it.
